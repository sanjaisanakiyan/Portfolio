METHODOLOGY

HOW I DESIGN GAMES

A structured 5-step iterative pipeline prioritizing player feedback, rapid validation, and technical polish.

01

IDEA

Define the gameplay concept, core fantasy, and player goal with clear constraints.

02

PROTOTYPE

Rapidly test mechanics, vehicle/character physics, and inputs using whitebox geometry.

03

BUILD

Develop gameplay systems, AI behaviors, environment layouts, UI, and state machines.

04

TEST

Playtest loops, identify player friction, debug edge cases, and refine the experience.

05

POLISH

Improve lighting, VFX, camera work, tactile feedback, and overall presentation.
